模块使用指导

外壳与内容
灰框与标题「编曲/音序/混音」为外壳；格子与滑条在 .module-body 内。只改 CSS 中 --chrome-* 压缩框高，--content-* 控制内容。URL 加 ?debug=layers 可橙框=外壳、青框=内容。
编曲时间轴
每个格子 1 小节（16 步），点击切换 Pattern（A–D），「+段」增加小节。
Pattern 库
编曲栏 A–D 切换当前编辑 Pattern，各段可分配不同 Pattern。
步进音序器
7 轨 × 16 步；鼓轨点击开关，旋律轨点击选音高。
混音
底部横条调节各轨音量，随草稿保存。
调性 / 音阶
顶栏选择根音与音阶，旋律选音仅在音阶内。
保存与草稿
自动保存草稿；顶栏「存/读/清」管理项目。
版本与更新
顶栏显示版本号；「更新」检测新版本；「日志」查看运行记录，可「复制日志」到剪贴板。更新后版本号以 version.json 为准。

快捷键

  • Space 播放 / 暂停
  • 1–4 切换 Pattern
